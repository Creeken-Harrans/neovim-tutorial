Neovim 零基础练习 02：移动

目标：
不用鼠标也能精准移动。先只练基础移动，再学前缀计数和行内搜索。

═══════════════════════════════════════════
第一部分：基础方向键替代
═══════════════════════════════════════════

| 按键 | 移动方向 |
|------|----------|
| h    | 左        |
| j    | 下        |
| k    | 上        |
| l    | 右        |

练习 1：用 hjkl 把光标从 START 移动到 END

═══════════════════════════════════════════
第二部分：单词移动
═══════════════════════════════════════════

| 按键 | 含义 |
|------|------|
| w    | 到下一个单词开头 |
| b    | 到上一个单词开头 |
| e    | 到当前/下一个单词结尾 |
| W    | 同上，但只用空格分隔（跳过标点） |
| B    | 上一个 WORD |
| E    | 到 WORD 结尾 |

练习 2：用 w / b / e 移动

把光标放到下面这行的第一个词上，依次按 w 向前跳，再按 b 向后跳，再按 e 跳到词尾：
alpha beta gamma delta epsilon zeta eta theta

═══════════════════════════════════════════
第三部分：行内移动
═══════════════════════════════════════════

| 按键 | 含义 |
|------|------|
| 0    | 到行首第 0 列（绝对行首） |
| ^    | 到本行第一个非空字符 |
| $    | 到行尾 |
| f{char} | 向前查找字符，光标停在字符上 |
| F{char} | 向后查找字符，光标停在字符上 |
| t{char} | 向前查找字符，光标停在字符前 |
| T{char} | 向后查找字符，光标停在字符后 |
| ;    | 重复上一个 f / F / t / T |
| ,    | 反向重复上一个 f / F / t / T |

练习 3：行内快速跳转

在下面这行里，按 fp 跳到 p，再按 ; 跳到下一个 p，按 , 回到上一个 p。
paradise_paradox_python_pattern_pandas

用 tp 停到字母 p 前面（不是停在 p 上）。

    这行前面有空格，试试 0 和 ^ 的区别

═══════════════════════════════════════════
第四部分：垂直移动
═══════════════════════════════════════════

| 按键    | 含义 |
|---------|------|
| gg      | 到文件开头 |
| G       | 到文件结尾 |
| 数字G   | 到指定行，例如 20G |
| :数字   | 同上，例如 :20 |
| {       | 到上一个空行（段落） |
| }       | 到下一个空行（段落） |
| %       | 在匹配的括号之间跳转 |
| Ctrl-d  | 向下滚半页 |
| Ctrl-u  | 向上滚半页 |
| Ctrl-f  | 向下滚一页 |
| Ctrl-b  | 向上滚一页 |

练习 4：垂直移动

1. 按 gg 到文件开头。
2. 按 G 到文件结尾。
3. 在 { 和 } 之间来回跳（光标放在空行分隔的两个段落中间）。
4. 把光标放在下面这些括号上按 %，感受括号跳转：
   function(param, [1, 2, {3, 4}])
5. 用 Ctrl-d / Ctrl-u 滚动半页，Ctrl-f / Ctrl-b 滚动一页。

第五部分：前缀计数
═══════════════════════════════════════════

几乎所有移动命令前面都能加数字，表示"重复 N 次"：

| 命令 | 含义 |
|------|------|
| 5j   | 向下 5 行 |
| 3w   | 向后 3 个单词 |
| 7k   | 向上 7 行 |
| 10G  | 跳到第 10 行 |

第六部分：搜索跳转
═══════════════════════════════════════════

| 按键    | 含义 |
|---------|------|
| /{word} | 向下搜索 word |
| ?{word} | 向上搜索 word |
| n       | 下一个搜索结果 |
| N       | 上一个搜索结果 |
| *       | 搜索光标所在的单词（向下） |
| #       | 搜索光标所在的单词（向上） |

练习 6：搜索单词

1. 输入 /target 然后回车，搜索 target。
2. 用 n 跳到下一个结果，用 N 跳到上一个结果。
3. 用 ?apple 向上搜索 apple。
4. 把光标放在 invoice 上，按 *（搜索这个词）。
5. 按 n / N 跳转结果。

invoice one
customer
subtotal
invoice two
discount
invoice three
target here
another target there

═══════════════════════════════════════════
第七部分：跳转列表
═══════════════════════════════════════════

Neovim 自动记录你"从哪里跳过来的"：

| 按键    | 含义 |
|---------|------|
| Ctrl-o  | 跳回上一个位置 |
| Ctrl-i  | 前进到下一个位置 |
| g;      | 上一个修改位置 |
| g,      | 下一个修改位置 |

练习 7：跳转列表

1. 按 gg 到文件开头。
2. 用 /target 搜索 target，按 Enter。
3. 按 Ctrl-o 回到文件开头。
4. 按 Ctrl-i 回到 target。
5. 随便改几个地方（i 输入点东西），然后按 u 撤销。
6. 按 g; 跳回上一个修改位置，再按 g, 前进。

═══════════════════════════════════════════
总结：你需要的移动能力
═══════════════════════════════════════════

初学只背这些：
  hjkl → 方向替代
  w / b → 单词
  0 / $ → 行首行尾
  gg / G → 文件首尾
  / + n/N → 搜索
  Ctrl-o → 跳回来

熟练后再加：
  e, ^, f/t, {/}, %, *, #, 数字前缀

不建议一次性背完。每天只加一个新动作，用到自然记住。
