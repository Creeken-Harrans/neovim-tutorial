Neovim 零基础练习 01：模式

目标：
理解 Neovim 的核心概念：大部分时间在普通模式，只有进入插入模式后才输入文字。

═══════════════════════════════════════════
第一部分：进入插入模式的所有方式
═══════════════════════════════════════════

不只有 i 一种方式进入插入模式。不同场景用不同入口：

| 按键 | 含义 | 使用场景 |
|------|------|----------|
| i    | 在光标前插入 | 最常用 |
| a    | 在光标后插入 | 光标后面加内容 |
| I    | 跳到行首插入 | 在当前行最前面加东西 |
| A    | 跳到行尾插入 | 在当前行最后追加内容 |
| o    | 在下面新开一行 | 在下面加代码 |
| O    | 在上面新开一行 | 在上面加 import 或注释 |
| s    | 删除光标下字符，进入插入 | 改一个字符 |
| S    | 删除整行，进入插入 | 重写当前行 |
| C    | 删除光标到行尾，进入插入 | 重写后半行 |
| cc   | 删除整行，进入插入 | 同上，但更直觉 |

练习 1：用不同方式进入插入模式
在下面每一行里，用对应的按键进入插入模式并输入内容，然后按 jk 回普通模式：

1. 把光标放这里，按 i，输入你喜欢的编辑器名：  (按 i)
2. 把光标放句号后面，按 a，继续写一句话：结束了. (按 a)
3. 按 I 跳到行首，加 "# " 前缀：这行加注释前缀 (按 I)
4. 按 A 跳到行尾，加 " -- end"：loop from 1 to 10 (按 A)
5. 在下面这一行按 o，新建一行输入 pass：
def empty_function(): (按 o)
6. 在上面这一行按 O，新建一行输入 import os：
print("hello") (按 O)
7. 光标放到下面数字上，按 s，输入一个新数字：
total = 4 (按 s)
8. 光标放下面这一行任意位置，按 S 重写整行：
old_broken_line_with_typos (按 S)
9. 光标放下面这一行，放到 = 后面，按 C，输入新值：

═══════════════════════════════════════════
第二部分：不下车的小修改（普通模式直接操作）
═══════════════════════════════════════════

这些操作在普通模式下直接执行，不需要进入插入模式：

| 按键 | 含义 |
|------|------|
| x    | 删除光标下的字符 |
| X    | 删除光标前的字符（退格） |
| r    | 替换光标下的一个字符（输完自动回普通模式） |
| ~    | 切换光标下字符的大小写 |
| dd   | 删除整行 |
| u    | 撤销 |
| Ctrl-r | 重做 |

练习 2：用小修改

1. 把光标放到字母 z 上，按 x 删掉它：
   frzmework -> 变成 framework
2. 把光标放到字母 b 上，按 r 然后输入 d：
   bad -> 变成 dad
3. 把光标放到字母 m 上，按 ~ 切换大小写：
   helloWorld -> （试一下）
4. 按 dd 删除下面这行乱码：
   asdfghjkl_qwerty_delete_me
5. 按 u 撤销第 4 步，再按 Ctrl-r 重做。

═══════════════════════════════════════════
第三部分：模式恢复——任何时候都不慌
═══════════════════════════════════════════

救命命令：
- Esc 或 jk：回到普通模式。
- u：撤销。
- Ctrl-r：重做。
- :e!  丢弃未保存修改，重新读取文件。
- :q!  不保存强制退出。

练习 3：有意改坏再恢复

1. 在下面这行随意输入几个字：
   recover_me_line
2. 按 :e! 恢复（丢弃修改）。
3. 随意输入，按 u 逐步撤销。
4. 按 Ctrl-r 逐步重做。

这些是最基础的操作。记住：任何时候不知道自己在哪，按 Esc（或 jk）。改了又后悔，按 u。
