这是一个刻意设计的小型 Python 项目，用于在本机 Neovim 配置下从零基础开始系统性地学习现代编辑器工作流。目标不是教 Python，而是让你脱离鼠标完成日常开发。

本文是 `tutorial-project/` 的唯一主线文档——不需要读别的，从头到尾跟着做就行。配套的配置说明在 `../README.md`，想了解插件和配置原理再去读。

## 第 0 课：打开项目、切换文件、基本生存

### 0.1 打开项目

在终端里执行：

```bash
cd /home/Creeken/Paper/neovim/tutorial-project
nvim .
```

`nvim .` 的意思是"用 Neovim 打开当前目录"。但你不会看到文件列表——本配置**禁用了 Neovim 内置的 netrw 文件浏览器**，换成了更现代的 **nvim-tree**。

按 `<leader>e`（空格 → e），左侧会弹出文件树：

- 用 `j` / `k` 上下移动光标
- 光标放到目录名上按 `Enter` 展开/折叠目录
- 光标放到文件名上按 `Enter` 打开文件
- 再按一次 `<leader>e` 关闭文件树

文件树适合在陌生项目里浏览目录结构。但在日常开发中，有更快的方式。

### 0.2 用 `<leader>ff` 查找并打开文件（主要方式）

Neovim 里最重要的一个操作：**按空格键不放，看一眼弹出的提示，再按两下 `f`**。

- `<leader>` = 空格键（Space）
- `<leader>ff` = 按一下空格 → 松开 → 按 `f` → 再按 `f`

执行 `<leader>ff` 后，屏幕中间会弹出一个模糊搜索框（Telescope 插件）。这个搜索框就是你的"打开文件"方式，等价于 VSCode 的 `Ctrl+P`。

接下来这样操作：

1. **输入文件名的一部分**，比如输入 `01_modes`，列表会实时过滤出匹配的文件
2. 用 `<C-j>`（Ctrl+j）往下移动光标，`<C-k>`（Ctrl+k）往上移动
3. 光标放到你要的文件上，按 `Enter` 打开
4. 如果不想打开任何文件，按 `Esc` 取消，回到原来状态

**现在就试**：按 `<leader>ff`，输入 `01_modes`，按 `Enter` 打开 `lessons/01_modes.txt`。

> **重要习惯**：以后你每次想打开一个文件，不要用 `nvim .` 进去翻目录，直接用 `<leader>ff` 搜索文件名。这是 Neovim 里最常用的操作之一。

### 0.3 在已经打开的文件之间切换

Neovim 里每个打开的文件叫一个 **buffer**。你可能会同时打开好几个文件，需要在这之间切换。有以下几种方式：

**方式一：buffer 列表（最直观）**

按 `<leader>fb`（空格 → f → b），弹出当前所有已打开文件的列表。用 `<C-j>` / `<C-k>` 上下选，按 `Enter` 切换过去。

**方式二：上一个 / 下一个 buffer（最常用）**

- `<leader>bp`（空格 → b → p）：切到**上一个** buffer（p = previous）
- `<leader>bn`（空格 → b → n）：切到**下一个** buffer（n = next）

打开两个文件后反复按 `<leader>bn` 和 `<leader>bp` 就能在两个文件间快速切换。这和 `Alt+Tab` 切换窗口的直觉一样。

**方式三：切回最近一个文件（实际开发中最快）**

Neovim 自带 `<C-^>`（Ctrl+Shift+6，也就是 Ctrl+^）：切回上一次编辑的 buffer。如果你在文件 A 和文件 B 之间来回，反复按 `<C-^>` 就是最快的。

**现在试一下**：

1. 你已经打开了 `01_modes.txt`（如果没打开，用 `<leader>ff` 打开它）
2. 按 `<leader>ff`，输入 `02_movement`，打开 `02_movement.txt`
3. 现在你有两个文件了。按 `<leader>bp` 回到 `01_modes.txt`
4. 再按 `<leader>bn` 回到 `02_movement.txt`
5. 按 `<leader>fb` 查看 buffer 列表，感受一下

**方式四：关闭当前 buffer**

按 `<leader>bd`（空格 → b → d）关闭当前文件。关闭后 Neovim 自动切到上一个 buffer。

如果你刚刚为了练习打开了不需要的文件，一个个关掉就行。

### 0.4 怎么保存文件

在**普通模式**下按 `<leader>w`（空格 → w），等价于 `:w<CR>`（输入 `:w` 然后回车）。

保存后文件底部会短暂显示 `"文件名" written`。

### 0.5 怎么退出 Neovim

- `<leader>q`（空格 → q）：正常退出（如果没有未保存修改）
- `:q!`：**强制退出**，丢弃所有未保存的修改
- `:wq`：保存并退出

### 0.6 不知道自己在哪怎么办——恢复操作

| 情况 | 按什么 |
|------|--------|
| 正在输入文字，想停下来 | `jk`（插入模式下快速连按 j 和 k）或 `Esc` |
| 改了东西后悔了 | `u`（撤销） |
| 撤销之后又想要回来 | `<C-r>`（重做，Ctrl+r） |
| 文件改乱了想全部恢复 | `:e!`（从磁盘重新读文件，丢弃这次打开后所有未保存修改） |
| 不想保存直接退出 | `:q!` |
| 屏幕上多了奇怪的窗口 | `<leader>sx`（空格 → s → x），关掉当前分屏窗口 |

**现在记住一句话**：任何时候慌了，按 `jk` 或 `Esc`，回到普通模式就安全了。

### 0.7 按键写法速查

| 写法 | 含义 | 具体怎么按 |
|------|------|-----------|
| `<leader>` | 空格键（Space） | 按一下空格，松开 |
| `<leader>ff` | 查找文件 | 按空格 → 松开 → 按 f → 按 f |
| `<C-r>` | Ctrl+r | 按住 Ctrl 不放，按 r |
| `<C-j>` | Ctrl+j | 按住 Ctrl 不放，按 j |
| `<CR>` | 回车 | 按 Enter |
| `jk` | 回普通模式 | 插入模式下**快速连按** j 然后 k |
| `:w` | 保存 | 在普通模式下输入 `:` → `w` → 回车 |
| `|` | 分隔符 | 不是按键，表示"或者" |

### 第 1 课：`lessons/01_modes.txt` — 模式

**你需要理解的第一件事**：Neovim 有多个"模式"。你最常待的是**普通模式**（Normal mode），它的作用是发命令——移动光标、删除、复制。只有当你真正想输入文字时，才从普通模式进入**插入模式**（Insert mode）。写完立刻退出回到普通模式。

这个文件的开头有一张表，列出了进入插入模式的 10 种按键。不是一个一个背的——文件中每一行都标记了应该用哪个按键，你照着做一遍自然就有体感。

**打开文件**：按 `<leader>ff`，输入 `01_modes`，回车。

#### 1.1 10 种进入插入模式的方式

文件第一部分里有 10 行练习句，每行末尾括号里写了该用哪个按键。操作步骤都是一样的：

1. 把光标移到那一行的**指定位置**（用 `j`/`k` 上下移动光标，用 `h`/`l` 左右移动——如果你还不熟 hjkl，没关系，第 2 课会专门练）
2. 按括号里写的按键（比如 `i`），进入插入模式（底部状态栏会显示 `-- INSERT --`）
3. 输入要求的内容
4. 按 `jk`（快速连按 j 然后 k）回到普通模式（底部状态栏的 `-- INSERT --` 消失）

比如第一个练习：

```
1. 把光标放这里，按 i，输入你喜欢的编辑器名：  (按 i)
```

光标放到这行的"："后面，按 `i`，输入几个字，按 `jk`。

这 10 个按键的区别：

| 按键 | 效果 | 你会用它干什么 |
|------|------|---------------|
| `i` | 在光标**前**开始插入 | 日常最常用的输入方式 |
| `a` | 在光标**后**开始插入 | 光标放句号后面，继续写一句话 |
| `I` | 跳到行首开始插入 | 在行最前面加 `#` 注释 |
| `A` | 跳到行尾开始插入 | 在行末尾追加内容 |
| `o` | 在当前行**下面**新开一行 | 在函数里加一行新代码 |
| `O` | 在当前行**上面**新开一行 | 在函数上面加 `import` |
| `s` | 删掉光标下字符，然后插入 | 改掉一个字符（比如把数字 4 改成 9） |
| `S` | 删掉整行，然后插入 | 重写当前这一整行 |
| `C` | 删掉光标到行尾，然后插入 | 重写行尾的值（比如改 `version = old_value` 后面那一截） |
| `cc` | 删掉整行，然后插入 | 和 `S` 一样，重写整行 |

初学不需要全部记住。记 `i`（最常用）、`a`（光标后）、`A`（行尾）、`o`（下面加一行），这四个就能覆盖 80% 的场景。其他的是优化——日后自然记住。

#### 1.2 不下车的修改（不进插入模式）

有些小修改连插入模式都不需要进，直接在普通模式下完成：

| 按键 | 效果 |
|------|------|
| `x` | 删掉光标下的那个字符 |
| `X` | 删掉光标**前面**那个字符（相当于退格键） |
| `r` | 替换光标下的字符为另一个（按 `r` 再按你要的字符，自动回普通模式） |
| `~` | 切换光标下字符的大小写（大写变小写，小写变大写） |
| `dd` | 删掉整行 |
| `u` | 撤销上一步 |
| `<C-r>` | 重做（把撤销的东西拿回来） |

**练习步骤**（文件里标记了第 2 部分的每一行）：

1. 在 `frzmework` 这行，把光标放到字母 `z` 上，按 `x`，`z` 消失，变成 `framework`
2. 在 `bad` 这行，把光标放到 `b` 上，按 `r` 再按 `d`，`b` 变成 `d`，变成 `dad`
3. 在 `helloWorld` 这行，把光标放到 `m` 上，按 `~`，看大小写变化
4. 在 `asdfghjkl_qwerty_delete_me` 这行，按 `dd`，整行消失
5. 按 `u` 撤销第 4 步，再按 `<C-r>` 重做

#### 1.3 救命指令

文件第三部分给出了遇到任何问题时的恢复方式：

```
- Esc 或 jk：回到普通模式
- u：撤销
- Ctrl-r：重做
- :e!  丢弃未保存修改，重新读取文件
- :q!  不保存强制退出
```

**练习**：在 `recover_me_line` 这行上随便输入点东西，按 `:e!` 然后回车——你会发现刚才输入的全部消失了，文件恢复了。这就是 `:e!` 的作用：从磁盘重读当前文件，丢弃本次打开后的所有未保存修改。

#### 1.4 帮自己记住这几个

- `jk` 或 `Esc` → 回到普通模式（任何时候）
- `u` → 撤销（错了就按）
- `:w` 或 `<leader>w` → 保存
- `:q!` → 不保存强制退出

**过关标准**：你不会再因为"不知道自己在哪个模式"或者"不知道怎么退出"而慌张。

### 第 2 课：`lessons/02_movement.txt` — 移动

**核心目标**：不用鼠标，只用键盘把光标定位到文件的任意位置。这是 Neovim 效率的来源——手不离开键盘主区域。

打开文件：按 `<leader>ff`，输入 `02_movement`，回车。

#### 2.1 基础方向键 h j k l

```
h ←  左
j ↓  下
k ↑  上
l →  右
```

这 4 个键替换方向键的理由：手不需要离开主键盘区去摸方向键，保持手指在 asdf / jkl; 这一排。

文件开头有个 `START` 到 `END` 的点阵，用 hjkl 把光标从 START 走到 END。这是你第一次不用方向键移动光标——刚开始会有点别扭，这是正常的，练 5 分钟就顺了。

**关键习惯**：从现在起，尽量**不要再按方向键**。刚开始一定会忍不住，没关系，有意识地纠正。不出三天 hjkl 就会成为本能。

#### 2.2 按单词移动 w b e

比 hjkl 快得多的是按单词移动：

| 按键 | 含义 |
|------|------|
| `w` | 光标跳到**下一个单词的开头** |
| `b` | 光标跳到**上一个单词的开头** |
| `e` | 光标跳到**当前/下一个单词的结尾** |
| `W` / `B` / `E` | 同上，但把**标点符号**也算单词分隔（更粗略的跳） |

w 和 W 的区别：在 `alpha.beta` 上，`w` 会停在 `.` 再停在 `b`，`W` 直接跳到 `b`。日常写代码用 `w` / `b` 就够了。

**练习**：文件里有一行 `alpha beta gamma delta epsilon zeta eta theta`，光标放第一个词，依次按 `w` 往前跳，再按 `b` 往回跳，再按 `e` 跳到词尾。反复练几遍，找到"跳单词"的感觉。

#### 2.3 行内移动 0 ^ $ f t

在**一行之内**快速定位：

| 按键 | 含义 |
|------|------|
| `0` | 跳到这一行的**第 0 列**（绝对行首，包括前面的空格） |
| `^` | 跳到这一行的**第一个非空字符**（实际内容的开头） |
| `$` | 跳到这一行的**末尾** |
| `f{char}` | 在行内**往前**找字符 `{char}`，光标**停在上面**。比如 `fp` 跳到下一个 `p` |
| `F{char}` | 在行内**往后**找字符 `{char}` |
| `t{char}` | 往前找字符，光标**停在它前面**。比如 `t(` 停在左括号前面 |
| `T{char}` | 往后找字符，光标**停在它后面** |
| `;` | 重复上一次 `f` / `t` 查找（继续找下一个） |
| `,` | 反向重复上一次 `f` / `t` 查找（往回找） |

`f` 和 `t` 是 Neovim 里最常用的行内移动。给你两个例子：

1. 你想跳到行尾的 `"` 后面：按 `f"` 跳过去
2. 你想删掉从光标到 `)` 之前的内容：按 `dt)` — d（删）+ t)（到 ) 之前）

`;` 和 `,` 让你可以连续找。比如文件里这一行：

```
paradise_paradox_python_pattern_pandas
```

光标放行首，按 `fp` 跳到第一个 `p`，再按 `;` 跳到下一个 `p`，再按 `;` 继续跳，按 `,` 往回跳。感受一下 `f` + `;` 的组合——这比用鼠标拖选快多了。

**0 和 ^ 的区别**：文件里有 `    这行前面有空格，试试 0 和 ^ 的区别`，光标放这行，按 `0` 光标到最左边，按 `^` 光标跳到"这"字前面。日常用 `^` 更多——你通常想去的是"内容开头"而不是"第 0 列"。

#### 2.4 垂直移动 gg G { } % 滚动

在文件范围移动：

| 按键 | 含义 |
|------|------|
| `gg` | 跳到**文件开头** |
| `G` | 跳到**文件结尾** |
| `20G` 或 `:20` | 跳到第 20 行（数字可以换成任意行号） |
| `{` | 跳到**上一个段落**（空行视为段落分隔） |
| `}` | 跳到**下一个段落** |
| `%` | 光标放在括号上，跳到**匹配的括号** |
| `<C-d>` | 向下滚**半页** |
| `<C-u>` | 向上滚**半页** |
| `<C-f>` | 向下滚**一页**（Page Down） |
| `<C-b>` | 向上滚**一页**（Page Up） |

**最常用的四个**：`gg`、`G`、`%`、`<C-d>` / `<C-u>`。其中 `<C-d>` 和 `<C-u>` 滚动半页最舒服——不是一整页让你丢失上下文。

`%` 在写代码时非常好用：光标放在左括号 `(` `[` `{` 上按 `%`，跳到对应的右括号。反过来也成立。这在看嵌套很深的代码时特别有用。

**练习**：

3. 在文件中有几段用空行隔开的文字（段落一、段落二、段落三），光标放段落一里按 `}` 跳到下一段，再按 `{` 回来

`03_editing_practice.py` 是一个 Python 文件，里面有大段的注释解释了每个练习怎么做。按 `<leader>ff`，输入 `03_editing`，回车打开。

#### 3.1 Vim 编辑语法的核心概念

Vim 的编辑像说一句话："**你要对哪片区域做什么**"。

**操作符**决定"做什么"：

| 操作符 | 意思 | 记忆方法 |
|--------|------|---------|
| `d` | **d**elete（删除） | 删掉 |
| `y` | **y**ank（复制、拉出来） | 复制 |
| `c` | **c**hange（修改） | 删掉后自动进入插入模式让你输入新的 |
| `>` | 向右缩进 | 增加缩进 |
| `<` | 向左缩进 | 减少缩进 |

**范围**决定"对哪片区域"——范围可以是一个移动命令，也可以是一个文本对象（下一节讲）。

**组成方式**：操作符 + 范围，例如：

- `dw` = d（删）+ w（到下个词首）= 删一个单词
- `d$` = d（删）+ $（到行尾）= 删到行尾
- `cw` = c（改）+ w（到下个词首）= 改一个单词
- `y$` = y（复制）+ $（到行尾）= 复制到行尾

**双击操作符 = 对整行操作**：

- `dd` = 删除整行
- `yy` = 复制整行
- `cc` = 修改整行（删除后进入插入模式）
- `>>` = 右缩进整行
- `<<` = 左缩进整行

练习文件里有一行：

```python
practice_operator_range = (
    "delete_part_of_this_line_for_practice another_word third_word"
)
```

在这行上练：`d$` 删到行尾（然后 `u` 撤销）、`dw` 删一个词（`u` 撤销）、`cw` 改一个词（输入新词，`jk` 退出，`u` 撤销）、`yw` 复制一个词（光标移到下面按 `p` 粘贴）。

**注意 `yw` 和 `yiw` 的区别**：`yw` 只复制从光标位置到词尾（光标必须在词首才复制整个词），而 `yiw` 复制整个词（不管光标在词的哪个位置）。日常用 `yiw` 比 `yw` 更多。

#### 3.2 文本对象（最重要的概念）

文本对象是 Vim 编辑中最强大的概念。它的格式是：

```
操作符 + i/a + 对象类型
```

- **`i`** = **i**nside（只操作**内容**，不包含边界符号）
- **`a`** = **a**round（操作内容 **+ 边界符号本身**，有时还包含前后空格）

对象类型就是边界符号：

```
w  = 单词     "  = 双引号     '  = 单引号
(  = 小括号   [  = 中括号     {  = 大括号
t  = HTML标签 p  = 段落       s  = 句子
```

最常见的 8 个组合，这 8 个记住就能处理日常 90% 的场景：

| 按键 | 含义 | 举例 |
|------|------|------|
| `ciw` | 修改**单词**内容 | 光标放在一个词上，改掉整个词 |
| `ci"` | 修改**双引号里面**的内容 | 把字符串 `"hello"` 改成 `"world"` |
| `ci'` | 修改**单引号里面**的内容 | 同上 |
| `ci(` | 修改**小括号里面**的内容 | 改函数参数 |
| `ci{` | 修改**大括号里面**的内容 | 改 dict 或代码块的内容 |
| `di[` | 删除**中括号里面**的内容 | 清空一个 list |
| `da"` | 删除双引号**和**里面的内容 | 把 `"hello"` 整段删掉 |
| `daw` | 删除单词**和它周围的空格** | 彻底移除一个词（包括留下的空格碎片） |

**文件里的练习段落**（第 2 部分，每个都有标记）：

- `example1 = "hello"` — 光标放 `hello` 上，按 `ci"`，输入 `world`，按 `jk`
- `result = sum(1, 2, 3)` — 光标放括号里面，按 `ci(`，输入新参数，按 `jk`
- `items = [1, 2, 3, 4]` — 光标放括号里，按 `di[`，中括号内容清空，按 `u` 撤销
- `config = {"name": "app", "port": 8080}` — 光标放大括号里，按 `ci{`，输入新内容
- `print("delete this entire string")` — 光标放这行任意位置，按 `da"`，整段引号内容消失
- `practice_spacing = "one two  three   four"` — 体会 `daw`（删单词+空格）和 `diw`（只删单词）的区别
- 段落选择：按 `vip` 选中一个段落（按空行分隔），然后按 `>` 缩进，`<` 恢复

**`ci"` 为什么比用鼠标选中再删除再输入快**：因为不管你光标在引号里什么位置，`ci"` 都能精准选中全部。不用鼠标，不用费力对准光标位置。

#### 3.3 `.` — 重复上一次修改（最重要的快捷键）

`.` 是 Vim 里最强的生产力提升键。它的作用：**重放你的上一次修改操作**。

举一个场景感受一下：

1. 光标放到 `["alpha", "bravo", "charlie", "delta"]` 里的 `alpha` 上
2. 按 `ciw`（改这个单词），输入 `foo`，按 `jk`
3. 光标移到 `bravo` 上，按 `.` → 自动变成 `foo`
4. 移到 `charlie` 上，按 `.` → 自动变成 `foo`
5. 移到 `delta` 上，按 `.` → 自动变成 `foo`

你只需要做一次修改，然后用 `.` 重放到各处。

另一个场景：你要把 5 个 `=` 改成 `==`。第一个改好（`s==`），后面四个光标移过去按 `.` 就行。

**学会 `.` 之后你的编辑就不是"做十次修改"而是"做一次修改 + 九次 `.`"。**

#### 3.7 寄存器 — 多个剪贴板

| `"1`-`"9` | 最近删除的内容（自动轮转队列） |

#### 3.8 宏 — 录制并重放操作

当你需要把同样的操作重复很多次时，用宏。它是 Neovim 里的"自动脚本录制器"：

1. 按 `qa` 开始录制到寄存器 a（底部状态栏出现 `recording @a`）
2. 执行你想重复的操作序列
3. 按 `q` 停止录制
4. 按 `@a` 重放宏（做一次你刚录的操作）
5. 按 `5@a` 重放 5 次
6. 按 `@@` 重放上一次执行的宏

**文件中的具体练习**——把 5 行变成引号括起来的行：

```python
macro_lines = ["line_0", "line_1", "line_2", "line_3", "line_4"]
```

步骤（一步一步来，不要急）：

1. 光标放到 `line_0` 的 `l` 上
2. 按 `qa` 开始录制
3. 按 `I`（大写 i）跳到行首
4. 按 `"`（输入一个双引号）
5. 按 `jk` 回普通模式
6. 按 `A`（大写 a）跳到行尾
7. 按 `"`（输入双引号），再按 `,`（输入逗号）
8. 按 `jk` 回普通模式
9. 按 `j` 下移一行（为下一次重放做准备——宏里的最后一步要准备好"下一次操作的起点"）
10. 按 `q` 停止录制
11. 现在按 `4@a`（对下面 4 行重放刚才录的操作）

结果：
```
"line_0",
"line_1",
"line_2",
"line_3",
"line_4",
```

按 `u` 撤销。

**宏的关键技巧**：录制时要确保操作对所有目标行都适用——用 `I`、`A`、`ciw` 这类"位置无关"的操作，不要用 `h`/`l` 微调。

#### 3.9 标记 — 给位置打书签

你在文件里四处跳转时可能需要回到某个重要位置。标记就是书签：

- `ma` = 设置局部标记 a（小写字母，只在当前文件有效）
- `mA` = 设置全局标记 A（大写字母，可以在其他文件里跳过来）

- `'a` = 跳到标记 a 所在行的**行首**（注意是单引号 `'`）
- `''` 或 ``` `` ``` = 跳回上一次跳转前的位置
- `'.` = 跳回你上次修改过的位置

**练习**：

2. 按 `gg` 到文件开头（或按 `G` 到结尾）
3. 按 `` `a `` 回到刚才设置标记的精确位置

#### 4.2 当前文件内替换

替换命令的格式是：

```
:{范围}s/{找什么}/{换成什么}/{标志}
```

逐部分解释：

| 片段 | 含义 | 例子 |
|------|------|------|
| `:` | 进入命令模式 | 在普通模式下按 `:`，然后输入后续字符 |
| `%` | 范围：**全文件** | `%` = 所有行（等价 `1,$`） |
| `10,20` | 范围：第 10 到 20 行 | 可以换成任意行号 |
| `s` | **s**ubstitute（替换） | 这是命令本身 |
| `/old/new/` | 把 `old` 换成 `new` | 两个斜杠分隔 |
| `g` | 标志：**g**lobal，一行内所有匹配都替换 | 不加 g 则每行只替换第一个 |
| `c` | 标志：**c**onfirm，每次替换前询问 | 最安全的方式 |
| `i` | 标志：**i**gnore case，忽略大小写 | 不常用 |
| `I` | 标志：区分大小写 | 不常用 |

**最常用的 4 个替换命令**：

| 命令 | 效果 |
|------|------|
| `:%s/old/new/g` | 全文件替换，不确认，全部改 |
| `:%s/old/new/gc` | 全文件替换，**每处确认**（推荐先用这个） |
| `:s/old/new/g` | 只替换**当前行** |
| `:10,20s/old/new/g` | 只替换第 10 到 20 行 |

在确认模式（带了 `c`）下，每处匹配会提示你选择：

- `y` = 替换这一处
- `n` = 跳过这一处
- `a` = 替换剩余所有（不再逐个询问）
- `q` = 退出替换（已经替换的不会撤销）
- `l` = 替换这一处后直接退出（这是最后一个了）

**练习**（在文件里的水果行上做）：
1. 执行 `:%s/apple/invoice/gc`
2. 每次弹出来按 `y` 或 `n`
3. 全部完成后按 `u` 全部撤销
4. 用 `V` 选几行，输入 `:'<,'>s/apple/orange/gc` 体验只替换选中范围

替换后要撤销，请在**普通模式**下按 `u`（不是在命令模式里）。

#### 4.4 正则表达式搜索

在搜索或替换时加 `\v` 前缀可以开启"very magic"模式，让正则表达式写法更接近标准正则：

| 模式 | 含义 | 例子 |
|------|------|------|
| `\v` | 开启 very magic 模式 | `/\v<apple>` |
| `\<` | 单词的左边界 | `/\v<in` 匹配以 `in` 开头的词 |

| `$` | 行尾 | `/return$` 搜索以 return 结尾的行 |

| `\s` | 空白字符 | `/\s\+$` 搜索行尾连续空格 |
| `\|` | 或者 | `/\v^(def\|class)` 搜索 def 或 class 开头的行 |
| `\+` | 一个或多个 | `/\s\+` 搜索一个或多个空格 |

### 第 5 课：`lessons/05_lsp_completion.py` — LSP 代码智能

这个文件包含一个 `Product` 数据类和两个函数 `calculate_total`、`format_receipt`，专门用来练习 Pyright（Python 语言服务器）提供的各种智能功能。

#### 5.1 什么是 LSP？这东西对应 VSCode 里的什么？

LSP（Language Server Protocol）是你编辑器里"IntelliSense"（代码补全、跳转到定义、查找引用、错误提示）的来源。在这个配置里，Python 的 LSP 由 **Pyright** 提供——它就是你在 VSCode 里装 Python 扩展时用的同一个引擎。

以下每个练习都提供了**两种快捷键**：一种是 `<leader>` 开头的（本配置自定义的），一种是 Neovim / LSP 标准的（比如 `gd`、`K`、`gr`）。**两种都可以用**，效果一样。初学建议先用本配置的（有 which-key 提示），熟练后可以用标准键更快。

#### 5.2 练习 1：Hover（光标悬停看文档）— K 或 `<leader>lh`

把光标放到 `Product` 上（比如第 7 行），按 `K`（就是大写 k，也就是 Shift+k），屏幕上方或下方会弹出一个浮动窗口：

```
@dataclass
class Product:
    name: str
    price: float
    quantity: int
```

这就是 Pyright 读到了这个类的定义，展示给你看。把光标放 `calculate_total` 或 `format_receipt` 上按 `K`，也会看到它们的签名。

**这和 VSCode 里把鼠标悬停在一个符号上的效果完全一样。**

#### 5.3 练习 2：跳转到定义 — gd 或 `<leader>ld`

在 `main()` 函数里（文件后半部分），有一行 `print(format_receipt(product, 0.08))`。把光标放到 `format_receipt` 这个函数调用上，按 `gd`（g + d）或 `<leader>ld`。

**`gd` 和 `<C-o>` 是写代码时最高频的组合之一**：随时跳去看定义，看完立刻回来。

#### 5.4 练习 3：查找引用 — gr 或 `<leader>lr`

#### 5.9 练习 8：Code Action（自动修复） — `<leader>la`

Code Action 是 LSP 的"智能修复"功能，对应 VSCode 的 `Ctrl+.`（灯泡菜单）。它能做的事情：

- 自动 import 未导入的模块
- 提取变量/函数
- 修复 Pyright 报的某些错误
- 添加类型注解

试着操作一下：在 `main()` 函数里加一行 `math.sqrt(16)`（故意不 import math）。保存后 Pyright 会报 `math` 未定义。光标放这行，按 `<leader>la`（空格 → l → a），弹出的菜单里应该包含 "import math" 之类的自动修复选项。

#### 5.10 练习 9：更多 LSP 跳转 — `<leader>li` / `<leader>lt` / `<leader>lD`

除了 `gd`（跳定义）和 `gr`（查找引用），还有三种跳转：

| 按键 | 功能 | 什么时候用 |
|------|------|-----------|
| `<leader>li` | Go to **Implementation** | 光标在抽象方法/接口上，跳到具体实现 |
| `<leader>lt` | Go to **Type Definition** | 光标在变量上，跳到它的类型定义 |
| `<leader>lD` | Go to **Declaration** | 跳到符号声明处（和定义可能在不同文件） |

本项目是纯 Python 小项目，`li` 和 `lD` 和 `gd` 结果往往相同，但知道它们存在就好——遇到大型项目时才会用到。

#### 5.11 练习 10：格式化和运行

- `<leader>lf`（空格 → l → f）：用 Black 格式化当前文件
- `<leader>rr`（空格 → r → r）：运行当前 Python 文件

注意：本配置已经设置了保存时自动格式化。所以你按 `<leader>w` 保存时，Black 会自动整理代码。`<leader>lf` 是不保存时就格式化——大多数时候你不需要手动触发。

#### 6.1 运行当前文件 — `<leader>rr`

这是你会反复使用的最重要快捷键。在**任何** Python 文件里按 `<leader>rr`（空格 → r → r），Neovim 会自动：

1. 把项目根目录加入 `PYTHONPATH`

| 按键 | 含义 | 会发生什么 |
|------|------|-----------|
| `↓` | **Step over** | 执行当前行，不进入函数内部。循环里每次按 `↓`，变量 `total` 会增加 |

| `←` | **Step out** | 跳出当前函数，回到调用处。如果你在函数内部想回到调用方，按 `←` |
| `↑` | **Restart frame** | 重启当前栈帧。把当前函数的执行倒回开头，让你重新执行 |

| 快捷键 | 作用 |

| `<leader>dt` | **停止**调试 |
| `<leader>dl` | 重新运行上一次的调试会话（不用重新选配置） |
| `<leader>dB` | 设置**条件断点**（弹出输入框让你输入条件，如 `score > 80`） |
| `<leader>dL` | 设置 **logpoint**（不暂停程序，只打印一条日志） |
| `<leader>dp` | 暂停正在运行的程序 |

```python
def build_invoice(customer: str, prices: list[float], discount_rate: float) -> Invoice:
    subtotal = 0.0
    for price in prices:
        subtotal = add(subtotal, price)          # ← 在这行设断点

    return Invoice(customer=customer, subtotal=discounted_total)
```

| `discounted_total` | — | — | — | 45.0（50.0×0.9） |
| `invoice` | — | — | — | `Invoice(customer="Debug Student", subtotal=45.0, discount_rate=0.0)` |

## 常见问题

### 不知道怎么从终端回到编辑器？

按 `jk` 或 `Esc`。如果焦点还在终端里，光标会变成方块而不是竖线——再按一次 `jk`。切回来后光标回到编辑器。

### 不小心多个窗口 / 分屏关不掉？

按 `<leader>sx`（空格 → s → x）一个一个关掉不需要的窗口。如果只剩一个分屏，`<leader>sx` 就是关掉它回到单窗口。

### 补全不工作？

1. `:Mason` → 看 `pyright` 是否在列表中，没装就装
2. `:LspInfo` → 看是否 attached 到当前 buffer
3. 手动触发补全：`<C-l>` 或 `<C-Space>`

### 运行 Python 时报 import 错误？

确认是通过 `<leader>rr` / `<leader>rm` 运行的——它们自动加 `PYTHONPATH`。如果在终端手动运行：

```bash
PYTHONPATH=/home/Creeken/Paper/neovim/tutorial-project python path/to/file.py
```

运行 pytest 的话直接 `cd` 到项目根目录再 `pytest`——`pyproject.toml` 里的 `pythonpath = ["."]` 会自动处理。

### `<leader>` 到底是什么键？

**空格键**。在本机配置中，空格键被设置为 leader。按一下空格等半秒，which-key 会弹出一个浮动面板，列出所有可用的后续按键。`<leader>ff` 就是：按空格 → 松开 → 按 f → 按 f。**不是同时按，是先后按。**

刚开始你会觉得这点别扭——但用一天就习惯了。每次不确定下个键是什么的时候，按完空格停下来，看面板提示。

### `jk` 到底是什么？

插入模式下快速连按 `j` 然后 `k`，等同于 `Esc`，回到普通模式。不是同时按，是先后快速按。

为什么不用 Esc？因为 Esc 在键盘左上角，每次去够它会打断打字节奏。`jk` 在 home row 上，两个手指几乎不用移动。这是 `better-escape.nvim` 插件提供的。

### 窗口间移动 `<C-w>h` 和 `<C-h>` 有什么区别？

没区别，都能切换到左边窗口。`<C-h>` 更短更好按。如果你也用 tmux 开终端分屏，这套快捷键在 Neovim 和 tmux 之间无缝移动——你在编辑器里按 `<C-l>` 跳到右边，到了终端分屏里还是按 `<C-l>` 跳到右边。这是 `tmux-navigator` 插件做的统一。

### 怎么知道配置更新了有哪些新快捷键？

- `<leader>fk`：搜索所有快捷键
- `<leader>fc`：搜索所有命令
- `:Lazy`：查看插件列表和更新
- `../README.md`：完整配置文档
