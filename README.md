# Neovim Tour Project

这是配套 `../README.md` 的练习项目，用来体验当前 Neovim 配置。

建议从这里打开：

```bash
cd /home/Creeken/Paper/neovim/tutorial-project
nvim .
```

推荐练习顺序：

1. 用 `<leader>ff` 打开 `app.lua`。
2. 用 `<leader>fg` 搜索 `greet` 或 `TODO`。
3. 在 `app.lua` 里体验补全、注释、搜索、替换。
4. 在 `math_utils.lua` 里体验 LSP hover、跳转、重命名。
5. 修改任意文件后观察左侧 Git 标记。
